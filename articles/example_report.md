# Example reports

Two reports from
[`render_report()`](https://thomuk.github.io/DBinventory/reference/render_report.md),
both run against the [Fake NHS Trust synthetic
dataset](https://github.com/ThomUK/synthetic-hospital-data) read through
its `fakehospdata` package, leaving out its `answers` schema (the mess
log and truth tables are the dataset’s answer key, not part of the
trust’s warehouse). The **sampled** report profiles large tables on a
sample of their rows, which is how a big warehouse is usually run. The
**full** report profiles every row of every table, so its distinct
counts and uniqueness are exact. They are regenerated by the
`example-reports` workflow on the repository’s Actions tab, run by hand.

| Report | Dataset | Sampling threshold | Tables | Tables sampled | Columns | Rows in total | FK candidates | Run time | Rendered |
|:---|:---|:---|---:|---:|---:|:---|---:|:---|:---|
| sampled | full set | 1,000,000 rows | 45 | 7 | 518 | 54,368,976 | 92 | 23 s | 2026-10-25 08:57 UTC |
| full | full set | none | 45 | 0 | 518 | 54,368,976 | 90 | 25 s | 2026-10-25 08:58 UTC |

To make one for your own database:

``` r

library(DBinventory)
inventory_run("Driver={ODBC Driver 18 for SQL Server};Server=...;Database=...;Trusted_Connection=yes;",
              organisation = "Your NHS Trust", store = "dw_inventory.sqlite", report = "dw_inventory.html")
```
