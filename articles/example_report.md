# Example reports

Two reports from
[`render_report()`](https://thomuk.github.io/DBinventory/reference/render_report.md),
both run against the [Fake NHS Trust synthetic
dataset](https://github.com/ThomUK/synthetic-hospital-data) read through
its `fakehospdata` package: one with the default sampling, where tables
above a row threshold are profiled on a sample, and one with sampling
switched off, which profiles every row of every table. The second is the
slower and more detailed of the two; comparing them shows what sampling
costs in detail and saves in time. They are regenerated by the
`example-reports` workflow on the repository’s Actions tab, run by hand.

The reports have not been generated yet. Run the `example-reports`
workflow from the Actions tab.

To make one for your own database:

``` r

library(DBinventory)
inventory_run("Driver={ODBC Driver 18 for SQL Server};Server=...;Database=...;Trusted_Connection=yes;",
              organisation = "Your NHS Trust", store = "dw_inventory.sqlite", report = "dw_inventory.html")
```
